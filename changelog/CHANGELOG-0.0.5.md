# CHANGELOG 0.0.5

自 0.0.4 以来的净变更：笔记时间精度提升至分钟级；新增正文编辑模板功能及独立管理页；工具栏排版按钮图形化；清理冗余 AI 注释。

## 新增

- **笔记时间戳精确至分钟**：
  - 笔记元数据（Front-matter）中的 `created` 与 `updated` 格式升级为分钟级精度（`YYYY/MM/DD/HH/mm` 或 `YYYY-MM-DD HH:mm`）。
- **正文编辑模板功能与独立管理页**：
  - 首页底部新增「模板管理」入口（`app/templates.tsx`），支持自定义习惯格式与排版模板，提供模板创建、编辑、删除与内置预设重置功能。
  - 笔记编辑器（`MarkdownEditor`）工具栏新增「≡ 模板」菜单，点击弹出模板列表，支持一键将模板内容插入至光标处（通过 `§` 符号定位光标位置），并提供跳转至管理页面的快捷链接。

## 改进

- **工具栏与操作按钮图形化**：
  - 笔记编辑工具栏的文字按钮升级为国际通用符号/图标（`B`、`I`、`===`、`S`、`</>`、`{ }`、`”`、`• -`、`1.`、`☐ 待办`、`☑ 完成`、`⊞`、`☍`、`[[ 链 ]]`、`◩`、`—`、`> 备注`、`◷ 日期`、`∑ 符号`）。
  - 底部操作按钮更新为 `‹ 返回` 与 `≡ 菜单`。
- **清理冗余注释**：
  - 清理 UI 组件与视图代码中的冗余 AI 注释，保持代码架构清晰。

## 构建与发布

- 版本三处同步：`package.json` / `app.json` → `0.0.5`；执行 `node scripts/gen-changelog.js` 重构 App 内置更新日志数据。
- tag `v0.0.5` 触发 CI 流水线。
