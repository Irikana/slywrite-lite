# CHANGELOG 0.0.4

自 0.0.3 以来的净变更：新增应用内「更新日志」页，全部版本的变更说明随应用内置，离线可查。

## 新增

- **应用内「更新日志」页**（`app/changelog.tsx`）：顶部是可横向滑动的版本时间线——菱形节点代表各版本，
  游标与进度线标出当前定位的版本；点击节点直接跳到该版本的说明卡片，向下滚动列表时时间线自动跟随。
  内容来自 `src/lib/changelog-data.ts`，随应用打包，**不需要联网**即可查看历史全部版本。
- **两个入口**：首页底部新增「更新日志」按钮，设置页「关于」段同样加入口；首页底部按钮行改为可换行，
  窄屏上四个按钮不会被挤出屏幕。
- **生成脚本 `scripts/gen-changelog.js`**：从 `changelog/CHANGELOG-*.md` 生成上面那份内置数据。
  只收录面向读者的节（新增 / 改进 / 修复）与版本摘要，构建与发布、硬约束记录等开发者节不进界面。

## 修复

- **首页底部按钮行在窄屏上会被挤出屏幕**：三个按钮已经贴近小屏宽度，加入「更新日志」后必然溢出；
  按钮行改为可换行（换行间距 8px），窄屏下自动折成两行而不是被裁掉。

## 构建与发布

- 正式发布链新增一步：写完 `CHANGELOG-{A.B.C}.md` 后必须跑 `node scripts/gen-changelog.js` 重新生成内置日志数据，
  否则发出去的版本里「更新日志」页看不到本次变更。
- 版本三处同步：`package.json` / `app.json` → `0.0.4`；tag `v0.0.4` 触发 APK 与 PC 两条流水线建 Release。

## 硬约束记录

- 未引入 GitHub Token / expo-secure-store / 任何凭据存储；「更新日志」页完全离线，不新增任何网络请求。
- 界面文案与代码注释无 emoji；UI 全部直角；颜色走 `useTheme()` 色板。
- 验证：`npx tsc --noEmit` 通过；生成脚本对现有三份 changelog 产出 3 个版本、30 条变更，
  界面可见文本中不再出现其他产品名与凭据类对照说明。
